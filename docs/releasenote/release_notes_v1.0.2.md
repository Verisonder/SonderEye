SonderEye 1.0.2, for Android and Windows.

- Satellites: when CelesTrak refuses (it gives each internet connection the same data once every two hours, so a phone and a PC at home can hit the limit), the app now waits out the two hours by itself instead of retrying, shows the last satellites it had, and says when it will try again.
- Error messages no longer tell you to turn a source off in Today unless it is a news site, and the same satellite error is shown once, not twice.

**Downloads**: `SonderEye-1.0.2.apk` (Android 8.0+), `SonderEye-1.0.2-Setup.exe` or `SonderEye-1.0.2-Portable.zip` (Windows 10/11). Install over the previous version; settings and keys stay.
